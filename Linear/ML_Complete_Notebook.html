1What is Machine Learning?
Old way Data+ Rules (Program)→ Output
ML way Data+ Output (answers)→ Machine learns the Rules
In one line Instead of a human writing every rule, we give the machine data + answers. It understands the pattern, learns the relationship, and builds its own rule-set (a trained model) — which it then uses to predict answers for new data.
2All 4 Types of Machine Learning
Supervised → Teacher gives Q + A
Unsupervised → No teacher, find it yourself
Semi-Supervised → Little teacher + tons of data
Reinforcement → Learn from reward + penalty

1. Supervised

Input + Output given

Model learns from questions AND answers, then predicts on new input.

flip →

Supervised — details

  • Regression: predicts a number (price, salary, temp)
  • Classification: predicts a category (spam / not spam)
  • Example: Area + Bedrooms → House Price
  • Algorithms: Linear/Logistic Regression, Decision Tree, KNN, SVM

2. Unsupervised

Input only, no answer

No target column — model finds hidden groups or patterns by itself.

flip →

Unsupervised — details

  • Clustering: groups similar data (customer segments)
  • Dimensionality Reduction: fewer features, same info (PCA)
  • Algorithms: K-Means, Hierarchical, DBSCAN, PCA
  • Uses: visualization, faster training

3. Semi-Supervised

Some labeled + lots unlabeled

Supervised + unsupervised combo — a little help, a lot of self-learning.

flip →

Semi-Supervised — details

  • Example: 1,000 labeled + 9,000 unlabeled images
  • Why: labeling everything is expensive & slow
  • Uses: image classification, speech recognition, medical imaging

4. Reinforcement

Actions → Rewards / Penalties

Agent tries actions in an environment, learns from trial & error.

flip →

Reinforcement — details

  • Agent: the learner (robot, game AI, self-driving car)
  • Environment: the world it acts in
  • State: current situation of the environment
  • Example: Tesla self-driving, game AI, robots
Easy way to remember Supervised = Teacher gives Q + A · Unsupervised = No teacher, find patterns yourself · Semi-Supervised = Little teacher + lots of data · Reinforcement = Learn from Rewards + Penalties

3ML Life Cycle (12 steps)

Example project used throughout: "AI to predict stock market prices"

1
Problem Statement — define exactly what you're solving.
2
Data Collection — gather data from Kaggle, APIs, or web scraping.
3
Data Preprocessing — remove duplicates, handle nulls, clean bad values.
4
Feature Engineering — add/fix columns, e.g. splitting a date column.
5
Train-Test Split — usually 80% train / 20% test.
6
Model Selection — pick an algorithm (Linear Regression, Decision Tree, etc.)
7
Model Training — feed the 80% data so the model can learn.
8
Model Evaluation — check accuracy on the unseen 20% test data.
9
Hyperparameter Tuning — try different settings to improve performance.
↑ happens on your local machine   |   ↓ moves to a live server
10
Deployment — go live via API, CI/CD, cloud hosting (AWS, Render).
11
Monitoring — keep watching the model + live data after launch.
12
Retraining — update with new data periodically so it stays accurate.

5Types of Data
StructuredNeat rows & columns, fixed schema.
Examples: Excel, CSV, MySQL.
UnstructuredNo fixed format.
Examples: images, videos, PDFs, Word docs — stored in MongoDB, Redis.
Semi-StructuredSome structure, not a full table.
Examples: JSON (key–value, APIs), XML (<name>Rahul</name>).
6Data Preprocessing
Missing / Null ValuesFill them in (mean/median/mode) or remove the row/column.
DuplicatesFind and remove repeated rows so they don't skew training.
OutliersValues far outside the normal range — detect (IQR / Z-score) and handle carefully.
7Encoding (Text → Numbers)

Algorithms only understand numbers — encoding turns text into numeric form.

Label EncodingGives each category a number. Red=0, Green=1, Blue=2.
⚠ can wrongly imply order/ranking.
One-Hot EncodingSeparate 0/1 column per category. Red→[1,0,0], Green→[0,1,0], Blue→[0,0,1]. Avoids false ordering.
8Feature Scaling

Different columns have different ranges (Age: 0–100 vs Salary: 0–10,00,000). Scaling puts everything on a fair, comparable scale.

NormalizationSqueezes values into a 0 to 1 range.
StandardizationRescales so the average becomes 0.
9Key Training Terms
PredictionThe answer the model gives for a new input.
AccuracyHow often the model's predictions are correct.
LossGap between real value and predicted value. Loss = Actual − Predicted. Lower is better.
EpochOne full pass through all training data.
e.g. 100 rows, epoch=3 → model sees all 100 rows, 3 times.
Learning RateSize of the "step" the model takes while learning.
Too high → overshoots. Too low → too slow.

Types of Regression
Simple LinearOne input → one output, straight line: y = mx + c
Multiple LinearMany inputs → one output: y = m1x1 + m2x2 + ... + c
PolynomialUsed when data forms a curve, not a straight line.
Logistic RegressionDespite the name, this is actually used for classification — predicts probability of a category (yes/no).
y = mx + c

y = predicted output  ·  x = input  ·  m = slope (learned)  ·  c = intercept (learned)

11Cost Function & MSE
Cost Function (Loss Function) Measures how wrong the model's predictions are overall. High cost = low accuracy. Low cost = high accuracy. Training = adjusting m and c until cost is as low as possible.
MSE = average of (actual − predicted)²

Squaring stops positive/negative errors from cancelling out, and punishes big mistakes more.
